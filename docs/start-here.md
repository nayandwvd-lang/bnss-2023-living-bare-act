# Start here

This guide covers the **Bharatiya Nagarik Suraksha Sanhita, 2023** (BNSS) — the statute that replaced the Code of Criminal Procedure, 1973 (CrPC) with effect from 1 July 2024.

## If you have never opened a bare Act

Start with any provision's **The dispute this solves** section. It puts a human situation in front of you before any statutory language, and works up from there. You do not need prior knowledge of criminal procedure to follow it.

## If you already know the CrPC

Every provision carries a **What changed from the CrPC** section: the old section number, the new one, whether the text actually changed, and — most importantly — what you must now do differently. Start there, or go straight to the [CrPC → BNSS concordance](/concordance) for a running list.

## How each provision is built

Every page in this guide follows the same six-stage structure, so once you know the shape of one you know the shape of all of them:

1. **The dispute this solves** — the human situation.
2. **The Act, decompiled** — the verbatim text, with mandatory, discretionary and defined-term language marked inline.
3. **How this actually runs** — the mechanical decision chain.
4. **In plain English** — the doctrine taken apart, element by element.
5. **What changed from the CrPC** — the concordance.
6. **Test your instinct** — scenarios you answer before the ruling is revealed.
7. **Practitioner HUD** — the winning ratio, sword and shield, limitation clock, interlocking matrix, the remaining authorities, and drafting strategy.

## A caution

This guide is educational and practice material, not a substitute for verifying the bare Act and current authority yourself. Verify every section number and every citation before relying on it in court.
